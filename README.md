# 🤖 COMO CRIAR SEU BOT NO DISCORD

## 📌 1. Criar uma aplicação

Acesse o **Discord Developer Portal**:

https://discord.com/developers/applications

Depois:

1. Faça login com sua conta Discord.
2. Clique em **New Application**.
3. Escolha um nome para seu bot.
4. Clique em **Create**.

---

## 🤖 2. Criar o Bot

Dentro da sua aplicação:

1. Acesse a aba **Bot** no menu lateral.
2. Clique em **Add Bot**.
3. Confirme a criação do bot.

Agora seu bot Discord foi criado.

---

## 🔐 3. Pegar o Token do Bot

Na página **Bot**:

1. Procure a seção **Token**.
2. Clique em **Reset Token** ou **Copy**.
3. Copie o Token gerado.

⚠️ **ATENÇÃO**

O Token do Discord é como uma senha.

**NUNCA envie seu Token para outras pessoas.**

**NUNCA coloque seu Token diretamente no GitHub.**

**NUNCA publique seu Token em grupos, vídeos ou prints.**

Se alguém tiver acesso ao seu Token, essa pessoa poderá controlar seu bot.

Se o Token for exposto:

1. Acesse o Discord Developer Portal.
2. Entre na sua aplicação.
3. Vá em **Bot**.
4. Clique em **Reset Token**.
5. Gere um novo Token.
